# 🧠 Curso de Mentalista

Um curso completo e gratuito de mentalismo, organizado em módulos baseados nos pilares do estudo:

- **Linguagem Corporal** — leitura de sinais não-verbais
- **Psicologia** — comportamento humano e tomada de decisão
- **Persuasão** — técnicas de influência e negociação
- **Detecção de Mentira** — como identificar sinais de engano
- **Dedução / Sherlock Holmes** — raciocínio lógico e observação
- **Memória** — técnicas de memorização
- **Mentalismo** — práticas e demonstrações
